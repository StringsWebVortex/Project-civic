## Files

- MANUAL_MINING_REPORT.md — corpus-wide topic counts, verified findings, architecture.
- page_catalog.tsv — 33,358 HTML pages indexed by title and technical topic hits.
- r18z1_2013_dtc_index.csv — 140 DTC-index rows with detail-page references and market qualifiers.
- R18Z1_DTC_DETAILED_EXTRACTION.md — full text extraction of 129 unique detailed DTC troubleshooting articles.
- HONDA_HDS_DATA_LIST_ITEMS.md — curated HDS Data List labels separated from generic SAE PIDs.
- R18Z1_ENGINE_WIRING_TEXT.md — all extracted text labels from the five 1.8L non-CNG engine-performance wiring sheets.
- NETWORK_TOPOLOGY_MATRIX.md — F-CAN, B-CAN, K-Line, S-NET and GA-NET access/interface matrix.
- wiring_diagram_index.csv — index of selected non-hybrid / 1.8L system wiring diagrams and source SVGs.
- ST_EDGE_AI_SETUP.md — installed ST Edge AI versions, Cortex-M4 runtime path, and NanoEdge availability.
- OWNER_VEHICLE_CONFIRMATION.md — owner-verified physical sensor/component baseline.
